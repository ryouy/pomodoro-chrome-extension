集中と休憩を切り替えるChrome拡張機能

## Features

- 作業・休憩時間・セット数・アラーム音を自由に設定
- ポップアップを閉じてもタイマーを継続
- 設定はすべてブラウザ内に保存

## Install

1. リポジトリをダウンロードして展開
2. Chromeで `chrome://extensions/` を開く
3. 画面右上の「デベロッパーモード」を有効にする
4. 「パッケージ化されていない拡張機能を読み込む」を押し、`manifest.json` があるフォルダを選ぶ
5. ツールバーの拡張機能アイコンから「シンプル・ポモドーロ」を開く

`manifest.json` では Chrome 116 以降を対象としています。

## 変更後の確認

ソースコードを編集した場合は、`chrome://extensions/` の拡張機能カードで「更新」を押して読み込み直してください。
設定値はブラウザ内に保存されます。不要なデータを消す場合は Chrome の拡張機能管理画面で対象拡張機能のデータ管理に注意してください。

ウェブ版のファイルは `web-app/` 以下にあります。
