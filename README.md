# シンプル・ポモドーロ

集中と休憩を切り替えるChrome拡張機能。

## Features

- 作業・休憩時間とセット数を自由に設定
- 5種類のアラーム音と鳥の声
- 5色のカラーテーマ
- 自動切り替え、通知、スキップ
- ポップアップを閉じてもタイマーを継続
- 設定はすべてブラウザ内に保存

初期設定は、作業25分・休憩5分・4セットです。

## Install

1. このリポジトリをダウンロードして展開します。
2. Chromeで `chrome://extensions/` を開きます。
3. 「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」から展開したフォルダを選びます。

## Web

ウェブ版は `web-app/` にあります。

Vercelで公開する場合は、Root Directoryを `web-app` に指定してください。
